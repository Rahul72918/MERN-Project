# 📂 Projects Included

## 1. LinkUp – Real-Time Social Platform

A full-stack social networking platform where users can connect, create posts, share stories, and chat in real time.

### Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- Clerk Authentication
- Redux Toolkit
- Tailwind CSS
- ImageKit CDN
- Inngest
- Server-Sent Events (SSE)
- Nodemailer

### Features

- User authentication and profile management
- Follow/unfollow users
- Connection requests
- Post creation with images
- Stories with auto-expiry
- Real-time messaging
- User discovery and notifications
